MOON ROVER

Six short games about directing a smart rover with incomplete instruments. The pass line is 60%. Careful spending of the limited data can clear 90%. Each version is its own session: different tools, different decisions, different palette.

PING BUDGET Spend eight scans, then commit a route. The rover samples what it crosses and dodges only the hazards you pinged. LAYER MAP Drive to paint one map layer at a time. Relief, heat, minerals, and ice radar each hide what the others show. DUAL LINK Split a cargo run and a rescue across two rovers. Orders and the partner’s position arrive late. ROVER'S PLAN The rover proposes the next stop from a thin reading. Accept it, edit the heading, or override. DUST RUN Deliver and rescue on a power budget while dust fronts blind the thermal and radio needles. TOOL LADDER Scoop easy soil to unlock a spectrometer, then a thermal probe, then the drill that can see ice.

Each page is self-contained and loads Three.js r170 from a CDN. The first view needs a network connection.
